Minimum Wage and Employment: A Replication of Card and Krueger (1994)

A Difference-in-Differences Analysis

Author

Wenwen Zhang

Published

April 21, 2026

Introduction

In this post, I replicate part of Card and Krueger (1994), which looks at how a minimum wage increase affects employment in fast-food restaurants.

The study compares New Jersey, where the minimum wage increased, to Pennsylvania, where it stayed the same. By comparing these two states before and after the policy change, the authors try to see whether higher minimum wages actually reduce jobs.

This is an interesting question because standard economic theory suggests that higher wages should reduce employment, but this paper challenges that idea using real data.

Main Analysis

To make this a real replication, I use the public Card and Krueger data to reproduce key results from the original paper. I focus on Table 3 and Table 4 because these tables summarize the main findings.

Replicating Table 3

pa_before = df.loc[df["state_name"] == "PA", "fte_before"].mean()
nj_before = df.loc[df["state_name"] == "NJ", "fte_before"].mean()

pa_after = df.loc[df["state_name"] == "PA", "fte_after"].mean()
nj_after = df.loc[df["state_name"] == "NJ", "fte_after"].mean()

pa_change = pa_after - pa_before
nj_change = nj_after - nj_before

table3 = pd.DataFrame({
    "PA": [pa_before, pa_after, pa_change],
    "NJ": [nj_before, nj_after, nj_change]
}, index=["Before", "After", "Change"])

table3["Difference (NJ - PA)"] = table3["NJ"] - table3["PA"]

table3.round(2)
PA NJ Difference (NJ - PA)
Before 23.33 20.44 -2.89
After 21.17 21.03 -0.14
Change -2.17 0.59 2.75

The table above shows the average employment levels before and after the policy change. The original paper reports very similar values (e.g., PA ≈ 23.33 and NJ ≈ 20.44 before the policy change). My replicated results closely match these values, confirming that the data has been processed correctly.

Replicating Table 4 Column (i)

reg_df = df.loc[
    df["fte_change"].notna() & df["state"].notna(),
    ["fte_change", "state"]
].copy()

reg_df["NJ_dummy"] = (reg_df["state"] == 1).astype(int)

X = sm.add_constant(reg_df["NJ_dummy"])
y = reg_df["fte_change"]

model = sm.OLS(y, X).fit()

table4 = pd.DataFrame({
    "Coefficient": model.params,
    "Std. Error": model.bse
})

table4.round(2)
Coefficient Std. Error
const -2.28 1.04
NJ_dummy 2.75 1.15

The estimated coefficient for New Jersey is close to the value reported in the original paper, which supports the same conclusion. The published Table 4 column (i) reports a coefficient of about 2.33 with a standard error of 1.19. My estimate of 2.75 is close to this value and leads to the same conclusion.

Something Additional

As an additional step, I compare my results to the original paper. The numbers are not exactly identical, but they are very close. Small differences are expected due to data handling choices.

Overall, the replication supports the paper’s conclusion that the minimum wage increase did not reduce employment.
